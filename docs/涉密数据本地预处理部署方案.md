**一句话**：这是"8GB 显存 + 大内存"的典型甜点位——**一次全 GPU 跑一个 7-9B 模型，小模型随意切，大模型靠内存兜底**。

## 1. 核心法则：一次一个 7-9B

| 模型规模 | Q4 量化权重 | + KV cache | 8GB 能否全加载 |
|---|---|---|---|
| 7B | ~4.5GB | ~1-2GB | ✅ 无压力 |
| 9B（你已有 Qwen3.5） | ~5.5GB | 需量化到 ~1GB | ✅ 开 `-ct q8_0` 后全加载 |
| 14B | ~8-9GB | - | ❌ 需 offload 50%+ 到内存 |
| 35B-A3B (MoE) | ~8-10GB | - | ❌ 需 16GB+ 或重度 offload |

> **结论**：你的机器最优规模是 **7B-9B**。14B 勉强能跑但速度掉一半，除非特定需求否则不推荐。

## 3. 显存调度策略（8GB 极限用法）

### 3.1 Ollama 环境变量（写进系统环境变量）

```bash
# 一次只加载一个模型，避免 OOM
OLLAMA_MAX_LOADED_MODELS=1
# 模型库放 D 盘（你已配置）
OLLAMA_MODELS=D:\ollamamx\.ollama\models
```

### 3.2 9B 模型全 GPU 加载（KV cache 量化是关键）

```bash
# 用 KV cache 量化 q8_0，省约 1GB 显存
ollama run qwen3.5:9b --verbose   # 检查 loaded layers 是否全 GPU
# 若仍溢出，手动限 GPU 层数（剩余层跑 CPU，40GB 内存兜底）
OLLAMA_GPU_LAYERS=20 ollama run qwen3.5:9b
```

### 3.3 工作流调度建议

| 时段 | 加载 | 说明 |
|---|---|---|
| 文本处理 | Qwen3.5 9B 独占 GPU | 清洗/结构化/摘要 |
| 图片批处理 | PaddleOCR + RT-DETR + LaMa | 三个小模型共 ~3GB，可同时 |
| 检索 | BGE-M3 纯 CPU | 与任何 GPU 任务并行 |
| 看图理解 | Qwen2.5-VL-7B 换下 9B | 需要时切换 |

## 4. 精确安装命令（RTX 4060 / CUDA 12.x / PyTorch 2.x）

### 4.1 独立 venv（环境隔离，禁止云端 API）

```bash
# 用你的 Python 3.11.8 建专用环境
py -3.11 -m venv D:\ai-local\venv
D:\ai-local\venv\Scripts\activate

# PyTorch CUDA 版（先装，其余依赖它）
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
```

### 4.2 图片预处理栈

```bash
pip install opencv-python paddlepaddle paddleocr      # OCR + 表格
pip install "paddlepaddle"                            # 检测框架
pip install lama-cleaner                              # 图像修复
pip install retinaface                                # 人脸打码（可选）
```

> RT-DETR 走 PaddleDetection，装好 paddlepaddle 后 `pip install paddledet` 或直接用 PaddleX 产线：`pip install paddlex`

### 4.3 数据预处理栈

```bash
pip install paddlenlp                                  # UIE 实体识别
pip install presidio-analyzer presidio-anonymizer     # PII 检测+脱敏
python -m spacy download zh_core_web_sm               # Presidio 中文 NER 模型
```

### 4.4 验证 GPU 可用

```bash
python -c "import torch; print('CUDA:', torch.cuda.is_available(), '| 显存:', torch.cuda.get_device_name(0))"
# 期望：CUDA: True | 显存: NVIDIA GeForce RTX 4060 Laptop GPU
```

## 5. 离线与安全落地

### 5.1 断网隔离

```bash
# 方案一：venv 内不装任何 API 客户端，模型全本地加载
# 方案二：防火墙阻断 python.exe 出站（Windows 防火墙高级设置）
# 方案三：hosts 屏蔽（不推荐，影响系统）
```

### 5.2 哈希校验（模型来源可信）

```bash
# Ollama：digest 自动校验（manifest.json 内含 sha256）
# 手动下载的模型（HuggingFace）：
certutil -hashfile model.safetensors SHA256
# 与 HuggingFace 页面公布的 sha256 比对
```

### 5.3 残留数据加密/销毁

```bash
# 加密存储：VeraCrypt 建加密盘（免费，MIT/自许可），产物写入后卸载
# 安全擦除临时目录：
cipher /w:D:\ai-local\tmp        # 覆写剩余空间
# 或：Eraser（免费开源）定时擦除
```
